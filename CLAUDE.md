# Working on phasor

This repository is the phasor library. The rules for changing it are in CONTRIBUTING.md:

@CONTRIBUTING.md

Before saying a change is done, run `uv run ruff check .`, `uv run ruff format --check .`,
`uv run lint-imports` and `uv run pytest`. To write scenes with phasor (rather than change
it), use `phasor kit` to set up a scenes folder: see README.md.
