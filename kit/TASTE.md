# Taste

What the person likes and dislikes, newest last. Read before every scene; it outranks the
examples. Add a dated line whenever they say something about taste.

- Dark by default (`midnight_glow`); light themes only when asked.
- The reference style is the prism look (`kit/examples/complex/prism_primes.py`): glowing
  strokes, a spectrum along curves, calm pacing.
- Fewer rainbows is not no rainbows: color that carries meaning (domain-coloring phase)
  keeps the full wheel.
