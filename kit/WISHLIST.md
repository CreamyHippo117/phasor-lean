# Wishlist

Things a scene needed that phasor could not do, newest last: what was wanted, which scene,
and the closest thing that was done instead. The person passes these on to phasor's
development.

- 2026-11-25, `scenes/reverb_la` (bug): `phasor render` with more than one worker drops every scene-local object whose drawing depends on state the script sets up at import (here a module-level registry of draw programs filled by the scene script). Workers rebuild the scene from its document and never run the script, so those objects draw nothing: the whole 17-minute preview came out as equations and sound only, while `storyboard`, `inspect` and `--workers 1` were correct. Wanted: workers that run the scene script (or a documented hook for it), or at least a warning when a worker's frame differs from the main process's. Done instead: the type re-runs the script itself when its registry is empty. **Built (2026-11-26):** workers run the scene script; `load` names the script in `meta.modules` so saved documents draw it too; each worker's first frame is checked against the parent's.
- 2026-11-25, `scenes/reverb_la`: wanted a "phasor field" object: many rotating hands (complex numbers r_k lambda_k^n) seated on a spiral, hue by angle per tick, with an exact motion-blur smear when a hand turns more than a few degrees per frame (preview has no blur, so a fast hand strobes). Done instead: a scene-local type drawing each hand's swept arc over a fixed shutter, lit by its shutter-averaged upness. **Built (2026-11-26):** `filt.PhasorField` with exact shutter blur (`frame_ticks`, `shutter`); example `reverb_modes`.
- 2026-11-25, `scenes/reverb_la`: wanted `cx.ComplexMap` to roll a plane conformally at every step (e.g. f_a(z) = (e^{a z} - 1)/a, the s-plane wrapping onto the unit disc); its `amount` blends z and f(z) linearly, which is not conformal in between. Done instead: the grid drawn by hand. **Built (2026-11-26):** `cx.ComplexMap(path="family")`, preset `roll`; example `s_plane_roll`.
- 2026-11-25, `scenes/reverb_la`: wanted note and sound events in a scene (`s.note(midi=69, at="marker", amp=)` with a dry synth voice, and `s.sound("x.wav", at=)`). Sound only reaches the video through narration blocks, so the scene mixes its own WAV and attaches it with the private `s._apply(SetNarration(...))`. **Built (2026-11-26):** as SOUND.md's cues: `s.cue(marker, "tone", midi=69, voice="pluck")` for a note, `s.cue(marker, "x.wav")` for a file, in the document's `sound` section (schema 9), mixed with the narration; examples `sound_harmonics`, `sound_bed`.
- 2026-11-25, `scenes/reverb_la`: one `label(x) near x` constraint in a long 3D scene (17 min) makes layout render depth buffers across the whole timeline, so even `s.at(...).morph(...)` took over 10 minutes. Wanted: layout that only bakes the times where the label is visible, or a warning. Done instead: a fixed-position Equation. **Built (2026-11-26):** the bake runs only while a label is shown, reuses itself across motion edits, verbs bake only up to their start; lint `slow_layout`.
- 2026-11-25, `scenes/reverb_la`: wanted a logarithmic (or "zoom") easing for `camera.distance`, so a 600x dive moves evenly; a smooth morph does almost all of it in the last few percent. Done instead: the dive split into staged morphs (x6, x8, x12). **Built (2026-11-26):** `ease="log:<curve>"`; camera distance/height morphs and `focus_pull` use it by default.
